# data/

| Path | What it is |
|---|---|
| `raw/` | The 7 source PDFs. **Not committed** — they're 58MB of third-party reports. See the main README for where to download them and what to name them. |
| `emissions_summary.csv` | Scope 1/2/3 figures pulled out of every report, generated by `src/emissions_extractor.py`. The `raw_answer` column keeps the model's full response so any value can be checked by hand. |
| `degree_scorecard.json` | Each company's stated targets alongside the progress my pipeline found in their own report, generated by `src/degree_scorer.py`. |

Both generated files are committed on purpose — they're the output the Streamlit
dashboard and DEGREE tabs read, so those tabs work without re-running anything.

## A note on the numbers

The same metric can legitimately have different values across reports. Siemens' Scope 3
appears as 416,758 thousand metric tons in one document and 178,835 ktCO2e in another,
because they cover different reporting boundaries. That's why every row carries the
page it came from rather than a single "correct" figure.
